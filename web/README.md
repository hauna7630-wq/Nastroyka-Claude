# web — Публичный сайт турбазы (React / Next.js)

Витрина для гостей: главная, о турбазе, домики, цены, бронирование, галерея, контакты.

## Структура
- `pages/`       — страницы сайта (роутинг по файлам)
- `components/`  — переиспользуемые UI-компоненты (Header, Footer, Card...)
- `styles/`      — глобальные стили и темы
- `public/`      — статика: изображения, шрифты
- `lib/`         — клиент к backend API, хелперы
