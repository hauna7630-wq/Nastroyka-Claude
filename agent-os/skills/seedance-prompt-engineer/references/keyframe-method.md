# Keyframe Method — Генерация по ключевым кадрам

> Основано на Neyrograph «Правила генерации по ключевым кадрам» + «Правила генерации из текста в видео». Техника двух ключевых кадров (first + last frame) даёт значительно больше контроля, чем чистый text-to-video.

---

## Два режима генерации

### Text-to-Video (T2V)
Текстовый промпт → видео. Модель сама решает всё.
- Быстро, просто
- Мало контроля над тем, как выглядит персонаж
- Хорошо для: природа, абстракция, простые сцены без людей

### Keyframe-to-Video (K2V)
Два изображения (начало + конец) + текстовый промпт → видео.
- Максимальный контроль: ты задаёшь точку A и точку B
- Модель интерполирует движение между ними
- Хорошо для: персонажи, продукт, сложные сцены, reveal-шоты

**Seedance, Kling AI, Minimax** — все поддерживают K2V.

---

## Text-to-Video: формула промпта

### Структура
```
[Стиль] + [Объект/Персонаж] + [Действие] + [Окружение] + [Детали]
```

### Уровни качества

**Простой:** `котенок играет с клубком`
→ Непредсказуемый результат. Модель сама решает стиль, ракурс, свет.

**Хороший:** `Крупный план, пушистый рыжий котенок игриво катает ярко-красный клубок шерсти по деревянному полу в залитой солнцем комнате.`
→ Есть крупность, субъект, действие, окружение, свет.

**Отличный:** `Кинематографичный кадр, вид с уровня пола. Маленький пушистый рыжий котенок с любопытными зелеными глазами толкает лапкой большой клубок красной шерсти. Старый паркетный пол, солнечные лучи пробиваются через окно, создавая длинные тени. Мягкий фокус на заднем плане. Высокая детализация шерсти.`
→ Ракурс, субъект с деталями, конкретное действие, среда, свет, глубина резкости.

### Чеклист T2V промпта
- [ ] Главный объект описан конкретно (не «девушка», а «young woman ~25 with wavy chestnut hair»)
- [ ] Действие задано глаголом (не «стоит», а «stepping forward, turning head slightly left»)
- [ ] Окружение + время суток + погода
- [ ] Ракурс камеры указан
- [ ] Свет описан физически (не `dramatic`, а `single soft key light from camera left`)
- [ ] Стиль/эстетика (cinematic / anime / UGC / documentary)

### Антипаттерны T2V
- ❌ `4K, ultra HD, masterpiece` — пустые слова, не влияют на результат
- ❌ `красивая девушка в парке` — нет деталей, AI решит за тебя
- ❌ Несколько действий в одном промпте — `бежит, потом прыгает, потом садится` → warp
- ❌ `dramatic lighting` без источника
- ✅ Одно действие + одна камера + одна атмосфера

## Keyframe-to-Video: полный метод

### Шаг 1: Подготовка ключевых кадров (самый важный)

**Правила согласованности:**

| Параметр | Требование |
|---|---|
| Логическая связь | Кадры 1 и 2 должны быть связаны логически. Нельзя: портрет → пейзаж Марса |
| Согласованность объекта | Главный объект сохраняет ключевые черты (если промпт не про трансформацию) |
| Стабильность фона | Фон максимально похож в обоих кадрах. Резкие изменения = глюки |
| Единое освещение | Стиль, палитра, тип света совпадают |
| Aspect Ratio | Оба изображения ОДИНАКОВОГО соотношения сторон. Разные = обрезка/искажение |

**Качество изображений:**
- Минимум 2K разрешение
- Чёткие, без артефактов
- Без водяных знаков, текста, логотипов

### Шаг 2: Промпт для перехода

**Главное правило: описывай ДЕЙСТВИЕ, а не СОСТОЯНИЕ.**

AI уже видит состояния на картинках. Твоя задача — описать глаголами **процесс**, который привёл от кадра 1 к кадру 2.

### Примеры

**Появление объекта:**
- Кадр 1: Пустое зелёное поле
- Кадр 2: На поле сидит собака
- ❌ `Собака сидит на поле` (состояние — AI уже это видит)
- ✅ `Весёлый золотистый ретривер вбегает в кадр справа и садится в центре поляны, радостно виляя хвостом`

**Изменение состояния:**
- Кадр 1: Целый помидор на столе
- Кадр 2: Тот же помидор нарезан
- ✅ `Нож быстро входит в кадр и нарезает помидор на ровные ломтики. Timelapse.`

**Движение + смена позы:**
- Кадр 1: Мужчина стоит у окна (съёмка со спины)
- Кадр 2: Он сидит в кресле, смотрит на камеру
- ✅ `Мужчина отворачивается от окна, медленно идёт к креслу и садится. Камера плавно отъезжает назад, следуя за ним.`

**Движение камеры (reveal shot):**
- Кадр 1: Крупный план объекта
- Кадр 2: Тот же объект в контексте (общий план)
- ✅ `Camera slowly pulls back, revealing the full environment around the subject. Smooth dolly out.`

### Шаг 3: Настройки генерации

| Параметр | Рекомендация |
|---|---|
| Длительность | 5-10 сек (sweet spot для K2V) |
| Aspect Ratio | Такой же как у ключевых кадров |
| FPS | 24 fps для кинематографичного, 30 для плавного |

## Продвинутые техники K2V

### Цепочка ключевых кадров
Для длинного видео: кадр 1→2, потом 2→3, потом 3→4...
Последний кадр предыдущего сегмента = первый кадр следующего.
Это даёт **визуальную непрерывность** через серию коротких генераций.

### Один кадр + промпт (Image-to-Video)
Загружаешь только стартовый кадр + текст. AI сам решает, как развить.
- Меньше контроля чем K2V, но больше чем T2V
- Хорошо для: «оживление» фотографии, лёгкое движение

### Серия с одним стилем
Генерируешь ключевые кадры в **одном стиле** (через image-prompt-engineer), потом собираешь видео из пар:
1. Сначала генерируешь 6-9 статичных кадров с character anchor
2. Потом попарно прогоняешь через K2V
3. Собираешь на таймлайне

Это **максимальный контроль** — ты контролируешь и визуал, и движение.

## Диагностика проблем K2V

| Проблема | Причина | Решение |
|---|---|---|
| Объект «вырастает из-под земли» | Промпт не объясняет, откуда взялся объект | Описать вход: `walks in from the right`, `enters through the door` |
| Резкий скачок вместо плавного перехода | Кадры слишком разные | Сделать промежуточный кадр, разбить на 2 перехода |
| Фон «плывёт» и деформируется | Разный фон в кадрах 1 и 2 | Согласовать фон, или зафиксировать через locked tripod |
| Лицо меняется в процессе | Нет identity preservation | Добавить `@Image1: Strict identity preservation` в промпт |
| Артефакты на одежде/ткани | Микро-паттерны, сложная текстура | `plain fabric, no micro-patterns, clean surfaces` |
| Слишком быстрое/медленное действие | Действие не вписывается в длительность | Подобрать длительность под количество действий |

## Когда что использовать

| Задача | Режим | Почему |
|---|---|---|
| Пейзаж, природа, абстракция | T2V | Нет персонажей, не нужен контроль лица |
| Простая сцена без людей | T2V | Быстро и достаточно |
| Персонаж в действии | K2V (image + промпт) | Контроль лица через @Image1 |
| Точный переход A→B | K2V (два кадра) | Максимальный контроль |
| Длинный ролик с персонажем | K2V цепочка | Консистентность через серию |
| Реклама продукта | K2V или T2V | Зависит от сложности |
| UGC/talking head | Image-to-Video | Загрузить фото, добавить движение |
