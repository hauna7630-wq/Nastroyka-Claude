# Model Selection: Nano Banana Pro vs Nano Banana 2 vs ChatGPT Image

Detailed reference for picking the right model. Read when the SKILL.md quick matrix isn't enough.

---

## Quick decision tree

```
Есть базовое фото для редактирования?
├── ДА → ChatGPT Image (input_fidelity=high)
└── НЕТ → генерация с нуля
    │
    Главная задача — текст в кадре?
    ├── Русский текст / кириллица → ChatGPT Image
    ├── Английский / сложная типографика / UI / инфографика → Nano Banana Pro
    └── НЕТ текста → дальше
        │
        Серия / много кадров / раскадровка?
        ├── ДА → Nano Banana 2 (скорость + consistency)
        └── НЕТ → один кадр
            │
            Реализм + люди + премиум?
            ├── ДА → Nano Banana Pro
            ├── Быстрый прототип → Nano Banana 2
            └── E-commerce продукт → Nano Banana 2 или ChatGPT Image
```

## Сильные стороны каждой модели

### Nano Banana Pro (Gemini 3 Pro Image)

**Главное:** студийное качество, максимальный контроль, сложные сцены.

- Лучший в классе текст-рендеринг (английский, мультиязык, типографика, UI, инфографика)
- Thinking Mode — модель «думает» перед генерацией, лучше сложные композиции
- До 5 персонажей в кадре, до 14 референсов
- Студийные controls: свет, камера, depth of field, color grade
- Native до 4K
- Скорость: 10–20 сек (медленнее 2)

**Когда брать:**
- Финальные ключевые кадры под рекламу или анимацию
- Много текста или сложная типографика в кадре
- Брендовые кампании, где качество критично
- Серии с несколькими персонажами и упором на consistency
- Постеры, обложки, key art

### Nano Banana 2 (Gemini 3.1 Flash Image)

**Главное:** скорость + 95% качества Pro.

- 4–6 секунд на генерацию (vs 10–20 у Pro)
- Image Search Grounding — реальные данные из Google в реальном времени
- 14 вариантов соотношений сторон (Pro — 10), включая 1:8 и 8:1
- Object fidelity: лучше квота под предметы (e-commerce)
- Поддерживает 5 персонажей, 14 объектов

**Когда брать:**
- Раскадровки 20–60 кадров для видео
- TikTok / Reels / Shorts серии
- Много вариантов сцены — лучшие потом доводим в Pro
- Связка Nano Banana 2 → Veo / Kling для анимации
- Продуктовые сцены e-commerce
- Прототипирование перед финалом в Pro

### ChatGPT Image (gpt-image-2)

**Главное:** редактирование с сохранением идентичности + лучший русский текст.

- Авторегрессивная архитектура (как GPT-4o) — понимает намерение, а не теги
- `input_fidelity="high"` — критично для face preservation при редактировании
- Лучший рендеринг русского текста при правильных инструкциях (`verbatim`, `Russian Cyrillic only`)
- Multi-turn диалоговое редактирование в ChatGPT интерфейсе
- API: `quality="low/medium/high"`, точный контроль размера
- Character anchor method — стабильная серия одного персонажа

**Когда брать:**
- Любое редактирование загруженного фото (смена одежды, удаление человека, замена фона)
- Реклама с русским текстом — особенно сложным (длинные слова, цены, юридические дисклеймеры)
- Inpainting / outpainting через диалог
- Композитные задачи: вставить человека в сцену, перенести стиль
- Серия одного персонажа через character anchor

## Edge cases и спорные ситуации

### Реклама с русским текстом + люди в реализме

Конфликт: Pro лучше для реалистичных людей, ChatGPT Image лучше для русского текста.

**Решение:** ChatGPT Image. Текст в реальной рекламе — критичнее, чем 5% разницы в реализме кожи. Если кожа выйдет «пластиковой», это правится промптом (`pores, natural imperfections, candid, unposed`). Сломанный русский текст — не правится никак.

Альтернатива: двухэтапный пайплайн. Сначала Pro генерирует чистую сцену без текста, потом ChatGPT Image добавляет текст поверх через редактирование.

### Storyboard с очень детализированным главным героем

**Решение:** Pro для якорного кадра + 2 для серии.
1. В Pro генерим idealный кадр персонажа со всей DNA.
2. Этот кадр становится reference для серии в Nano Banana 2.
3. Финальные ключевые кадры (обложки, кульминация) — снова в Pro.

### E-commerce: один продукт в десятке сцен

**Решение:** Nano Banana 2 для серии, ChatGPT Image если нужно вставить продукт в существующую сцену.
- Pro избыточен по цене и скорости.
- 2 даёт object fidelity и быстрые итерации.
- Если нужно вставить продукт в готовый lifestyle кадр — ChatGPT Image с `input_fidelity=high`.

### Аватарки для гейминга (PUBG, esports)

**Решение:** Nano Banana Pro для финального аватара + character anchor.
- Гейминг-эстетика требует точного контроля света и эффектов (rim light, particles, neon).
- Pro лучше делает «esports key art» стиль.
- Nano Banana 2 — для серии вариаций после финализации.

### Инфографика на русском

**Решение:** ChatGPT Image.
- Pro лучше для английского текста и сложной типографики, но русский на инфографике (много слов, числа, заголовки) лучше идёт через ChatGPT Image с `verbatim` инструкцией.

### Колоризация / реставрация старых фото

**Решение:** Nano Banana Pro или ChatGPT Image. Обе хорошо справляются. Pro даёт более кинематографичный результат, ChatGPT Image — более «честный документальный».

## Как формулировать выбор пользователю

Один-двумя строчками:

> Модель: **Nano Banana Pro** — реалистичный портрет с человеком + текст в кадре, нужна максимальная чёткость.

> Модель: **ChatGPT Image** — на фото лицо клиента, нужно редактирование с сохранением идентичности.

> Модель: **Nano Banana 2** — серия из 12 кадров для раскадровки, скорость важнее идеала.

Не объясняй каждый раз весь tradeoff. Одна причина — самая весомая.
