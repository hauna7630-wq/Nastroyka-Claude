# Typography & Text Design (2025–2026)

Reference for fonts, text placement, and typography in ad creatives, banners, and short-form video. Read when the task involves text in frame, banners, posters, infographics, or visuals for TikTok/Reels/Shorts.

---

## Базовые принципы

- **Главное — мгновенная читаемость на телефоне**, а не «красивый» шрифт
- **Максимум 1–2 строки текста в кадре**
- **Длина строки 32–42 символа** (5–7 слов) — длинные строки ломают retention
- **1–2 шрифтовых семейства**, 2–3 веса (Regular / Medium / Bold). Больше = «ransom note effect», ощущение самопала
- **Высокий контраст текста с фоном** — низкоконтрастный «стильный» текст не читается на движущемся фоне

---

## Шрифты, которые работают

### Универсальные надёжные (читаемость)

- **Системные / классика:** Roboto, Open Sans, Lato, Montserrat, Arial, Helvetica
- **Современные «социальные»:** Poppins, Raleway, Quicksand — округлые, дружелюбные, отлично читаются крупно
- **Жирные display для хука:** Bebas Neue, Impact, Anton, Oswald, Montserrat Bold, Druk
- **Конденсированные для узких форматов:** Oswald, Roboto Condensed, League Gothic

### Тренды 2025–2026

- **Neo-humanist гротески:** Geist (Vercel), Inter, Manrope, Urbanist, Satoshi, Aeonik, PP Mori
- **Bold display:** PP Monument Extended, Druk
- **Soft serif для luxury / beauty:** Editorial New, Recoleta, Playfair Display, Cormorant Garamond, Lora
- **Variable fonts** — для motion-типографики (анимация веса / ширины)

### Чего избегать

- Скриптовые, декоративные, ультратонкие (Hairline, Ultra Light) шрифты в основном тексте
- Экстремально condensed шрифты для субтитров — рассыпаются на маленьком экране
- Коллаж из 4–5 шрифтов и десятка стилей одновременно

## Размещение текста в 9:16 (TikTok / Reels / Shorts)

Canvas — 1080×1920, но интерфейс «съедает» края.

### Safe zones

- **Ключевой текст, лица, CTA — в центральной зоне**: ~60–70% по высоте и ширине
- **Избегать нижних 20–35%** — там подписи, описания, кнопки (особенно в Reels и TikTok)
- **Избегать верхних 10–15%** — там имя автора, иконки

Meta safe-zones (px):
- Top: ~220–270 px
- Bottom: ~450–670 px (Reels требует больше «воздуха» снизу, чем Stories)
- Боковые: 35–65 px

**Стратегия:** проектировать мастер-ролик 9:16, держать всё ключевое внутри центрального квадрата 1:1, слегка смещённого от правого края — чтобы работало во всех плейсментах Meta.

### Где что размещать

- **Хук-заголовок** — верхняя часть центральной зоны (читабельно при скролле)
- **Субтитры / реплики** — нижняя часть центральной зоны, строго над подписью платформы. 1–2 строки.
- **Подписи / буллеты выгод** — левый или правый край центральной зоны. Не перекрывать лицо / объект.
- **CTA** — чуть выше нижнего UI, по центру. С воздухом, чтобы не сливаться с системными кнопками.

### Композиционные правила

- **Одна ось выравнивания** для текста в кадре (лево или центр). Центрировать «всё подряд» = плохая типографика.
- **Одна смысловая единица на экран**: хук отдельно, выгода отдельно, CTA отдельно
- **Сначала кадр и персонаж, потом текст** — не закрывай лицо и ключевой объект

## Контраст: как сделать текст читаемым на сложных AI-фонах

AI-картинки дают много деталей и шума — текст легко «тонет».

### Приёмы усиления контраста

- **Подложка под текст** — полупрозрачный прямоугольник (тёмный для светлого текста и наоборот). Самый надёжный приём.
- **Stroke / outline** — тонкий контур контрастного цвета вокруг текста. Читается на любом фоне.
- **Drop shadow** — лёгкая тень с небольшим смещением, 40–60% непрозрачности. Отделяет текст от фона.
- **Blur-плашка** — размытие части фона под текстом + затемнение. Даёт «чистый баннер» поверх сложного изображения.

### Цвет и бренд

- **2–3 бренд-цвета** для текста и подложек. Больше = визуальный шум.
- **Универсальный приём для субтитров**: белый / светлый текст на тёмной подложке. Работает на любом видео.
- **Цветом выделяй только ключевые слова** (боль, результат, скидка), не каждое второе

### Чек-лист теста

- Тест «на вытянутой руке»: читается ли фраза за 1–2 секунды? Если нет — переделать.
- Проверка на разной яркости экрана (светлое помещение / улица).
- Дай ролик человеку, который не знает текста: что он реально успел прочитать?

## Кинетическая типографика (motion text)

К 2025–2026 kinetic typography — один из главных языков визуального сторителлинга.

**Текст движется с намерением:** входит, выходит, масштабируется, пульсирует в такт речи / музыке, усиливая акценты.

### Что даёт

- Мгновенная понятность (ключевые слова появляются в нужный момент)
- Меньшая когнитивная нагрузка — длинные фразы дробятся на короткие «биения»
- Рост perceived production value без сложного продакшена

### Современные паттерны

- **Audio-reactive текст** — пульсации, изменения веса / размера в такт голосу или музыке
- **Fluid transitions** — плавное перетекание слов, одно слово плавно morph’ится в другое
- **Simple motion** — минимум эффектов, аккуратные fade / slide / scale (для образовательного и B2B контента)
- **3D / AR-текст** — для шоу-кейс роликов (тизеры, бренд-анонсы), не обязателен в перформансе
- **Liquid text effects** — текучие, деформирующиеся буквы

**Критичное:** не «чем больше движения, тем лучше». Движение = смысл. Если анимация не помогает понять — убрать.

## Шаблоны под форматы

### Перформанс-реклама (TikTok / Meta / Shorts)

Структура хука 0–15 сек:

1. **0–1 сек: хук** (1–6 слов), крупный, центр-верх
   - «Stop editing videos manually», «Your ads are burning money»
2. **1–3 сек: усиление боли**
   - «You're doing this wrong…», «99% freelancers forget this»
3. **3–8 сек: доказательство / демо** (буллеты рядом с экраном продукта)
   - «Auto captions in 1 click», «+30% watch time on Reels»
4. **8–12 сек: социальное доказательство**
   - «Trusted by 50k creators», короткие отзывы
5. **12–15 сек: CTA**
   - «Try it free today», «Download via link»

Каждая фраза = отдельный блок, короткая анимация (scale / slide / fade), на экране 1.5–3 сек, без того чтобы 3 текста жили одновременно.

### Органический обучающий

- В начале: заголовок-обещание — «3 text tricks for viral Reels»
- Каждый шаг — отдельный кадр с текстом:
  - Step 1: «Use bold, high-contrast fonts»
  - Step 2: «Keep lines under 7 words»
  - Step 3: «Animate with your beat»
- Субтитры, появляющиеся фразами синхронно речи
- В конце мягкий CTA: «Save this to fix your next video text»

### Реклама vs органика

| | Реклама | Органика |
|---|---|---|
| Текст | Кратчайший, 1 тезис на кадр | Подлиннее, сторителлинг |
| Иерархия | Жёсткая: хук → выгода → CTA | Свободнее |
| Тон | Чёткий месседж + ясный CTA | Разговорный, мемы / сленг |
| Брендирование | Сильное: цвета, логотип, продукт | Допускается мягче |
| Анимации | Чистые, читабельные | Можно экспериментальнее |

## Ошибки, из-за которых текст выглядит «дёшево»

1. **Много разных шрифтов** — типичный «ransom note»
2. **Низкий контраст** — светло-серый на светлом, пастель на пастели
3. **Слишком мелкий кегль** — читается на мониторе, но не в ленте на телефоне
4. **Нет иерархии** — все надписи одинаковы по размеру и весу, глаз не понимает за что зацепиться
5. **Центрировано всё подряд** — заголовки, подзаголовки, цены, CTA. Хаос.
6. **Дикий motion** — вращения, грубые пресеты, анимация не служит смыслу
7. **Нарушение safe-zones** — текст обрезан или спрятан за UI платформы
8. **Слишком много текста** — пользователь физически не успевает прочитать, retention падает

## Чек-лист текста в кадре

Перед сдачей:

- [ ] Не более 1–2 строк, 5–7 слов в строке
- [ ] 1–2 шрифта максимум, 2–3 веса
- [ ] Высокий контраст с фоном (или подложка / stroke / shadow)
- [ ] Иерархия видна — главное больше / жирнее остального
- [ ] Текст в safe-zone (для 9:16: центральные 60–70%)
- [ ] Одна ось выравнивания
- [ ] Каждая смысловая единица — отдельный экран / момент
- [ ] Тест «на вытянутой руке» прошёл — читается за 1–2 секунды
