# Film Grammar — Грамматика кино и драматургия персонажа

> Основано на Никос Прокурис «Film Directing Fundamentals» (перевод). Это правила, нарушение которых зритель чувствует телом — даже не понимая почему. И инструменты для построения персонажа, которому хочется сопереживать.

---

## ПРАВИЛО 180° — Ось действия

**Суть:** между двумя персонажами (или персонажем и объектом) проходит воображаемая ось. Камера должна оставаться по одну сторону от этой оси в течение всей сцены.

**Что происходит при нарушении:** оба персонажа начинают смотреть в одну сторону — зритель теряет ориентацию в пространстве, ломается динамика диалога.

### Когда можно нарушить

1. **Камера «переезжает» ось в движении** — если зритель видит момент перехода, пространство не «ломается».
2. **Нейтральный кадр с обоими персонажами** — показывает новое расположение, зритель понимает, что произошло.
3. **Намеренный драматический эффект** — Хичкок в «Таксисте» нарушает ось 4 раза, подчёркивая отчаяние побега. Скорсезе в «Китайском квартале» — в момент эмоционального взрыва.

### Для раскадровки и shot list

```
Правило-якорь: фиксируй позиции персонажей в первом кадре.
Пример: «Женщина всегда слева, мужчина справа — во всех кадрах сцены.»
```

**Для AI-видео:** это самое важное constraints-правило при мультишотовом промпте. Без фиксации — модель «перетасует» персонажей случайно.

## ПРАВИЛО 30° — Смена ракурса

**Суть:** если склеиваешь два кадра с одним и тем же персонажем без промежуточного кадра — угол должен измениться минимум на 30°.

**Что происходит при нарушении:** камера «прыгает» в пространстве, зритель замечает монтаж.

**Исключения (работают без последствий):**
- Персонаж в движении
- Во втором кадре есть элемент переднего плана (абажур, ветка, рука)
- Существенная смена крупности (дальний → крупный)

**Намеренное нарушение:** Хичкок в «Птицах» — три кадра подряд с одного ракурса, только крупность меняется (средний → среднекрупный → крупный). Создаёт давление, нагнетание. Используй для кульминаций.

## НАПРАВЛЕНИЕ В КАДРЕ

### Слева направо / справа налево

- **Слева направо** — «удобное» направление для западного зрителя (привычка читать). Ощущение движения к цели, прогресса.
- **Справа налево** — создаёт напряжение, сопротивление, регрессию.
- **Справа налево + вверх** — максимальное напряжение. Хичкок использовал в «Головокружении» (финальный подъём на колокольню).

**Правило непрерывности направления:**
Если персонаж уходит из кадра вправо → в следующем кадре должен войти слева. Иначе зритель решит, что персонаж развернулся.

**Намеренное нарушение:** серия смен направления (вправо → влево → вправо) с разными ракурсами = напряжение погони, хаоса, срочности. Последний кадр серии должен соответствовать «правильному» направлению.

### Для shot list

Всегда указывай направление движения в кадре:
- `character walks left to right` — движение к цели
- `character approaches camera from right` → `enters next frame from left`
- `emergency vehicle alternating directions across cuts` — напряжение

## ВРЕМЯ ФИЛЬМА vs РЕАЛЬНОЕ ВРЕМЯ

> «Все скучные части истории мы сжимаем, все интересные — растягиваем.»

**Сжатие (ellipsis):** убираем скучные этапы действия. Зритель ощущает скачок во времени. Работает через смену локации, смену времени суток, переходные кадры.

**Растяжение:** замедляем ключевой момент. Хичкок в «Птицах» растягивает 2 секунды обнаружения трупа через 3 последовательных кадра с нарастанием крупности.

**Формула растяжения:**
```
1 средний план (контекст) → 1 среднекрупный (реакция) → 1 крупный (деталь)
Магическое число = 3: первые два кадра задают паттерн, третий — ударный.
```

**Для beat sheet:** каждый beat — это единица «интересного времени». Между битами можно сжимать. Внутри кульминационного бита — растягивать.

## ДРАМАТУРГИЯ ПЕРСОНАЖА (Прокурис)

### Герой = Психология → Поведение

Ключевой принцип Казана: **«Превратить психологию в поведение».** Не объяснять характер персонажа — показывать через действия.

Действие фильма происходит в настоящем. **Личность героя формируется в прошлом.** История берёт из прошлого только нужный багаж.

### Четыре элемента персонажа

**1. Обстоятельства** — ситуация, в которой находится персонаж. Объективные (что есть) и субъективные (как персонаж это воспринимает). Разрыв между ними = конфликт восприятия.

**2. Стремления (цели)**
- **Главная цель** — то, чего герой хочет во всём фильме
- **Цели сцены** — более мелкие, неотложные желания в конкретный момент
- Мини-цели могут **конфликтовать** с главной → это лучший драматургический вариант

**3. Препятствия** — создают базу для борьбы. Без препятствия нет конфликта. Без конфликта нет истории.

```
«Ты будешь любить меня всю жизнь?» — «Конечно.» — Конец фильма.
«Ты будешь любить меня всю жизнь?» — «Отстань, придурок!» — Начало фильма.
```

**4. Желания vs потребности** (по Мику Джаггеру)
«Вы не всегда получаете то, что хотите, но можете получить то, что вам нужно.»
Конфликт между желаемым и нужным = ирония, трагедия, комедия — в зависимости от жанра.

### Динамические отношения

Статичные отношения (муж/жена, начальник/подчинённый) — это факты. **Динамические** — то, как один персонаж ВИДИТ другого в конкретный момент.

Отец может видеть сына как «разочарование» → через 30 минут как «чемпиона». Это изменение = **драматический сок истории**.

Вопрос для каждой сцены: **«Как персонаж А видит персонажа Б прямо сейчас?»**

## БИТЫ ДЕЙСТВИЯ

**Бит действия** = единица действия персонажа. Описывается глаголом:
- приветствовать, обвинять, соблазнять, игнорировать, угрожать, утешать

**Закон одного действия:** герой совершает только одно действие за раз. Нельзя «включить свет и открыть окно одновременно» (упражнение Мейснера).

**Важно:** актёры играют не эмоции — они играют **действия**. Эмоции возникают как результат действий в данных обстоятельствах.

**Диалог — это тоже действие.** «Здравствуйте» может быть приветствием или выговором — зависит от обстоятельств и стремлений.

**Новый бит начинается когда меняется действие персонажа.** Beat sheet в видео = последовательность битов действия.

## КАК ПРИМЕНЯТЬ В РАБОТЕ

### При создании логлайна

Проверь: есть ли в логлайне все элементы?
```
[Герой с чёткой личностью] + [главная цель] + [препятствие] + [конфликт желания vs потребности]
```

### При написании beat sheet

Для каждого бита задай вопросы:
1. Какова цель персонажа в этот момент?
2. Что ему мешает?
3. Какое действие он совершает? (глагол)
4. Как меняется то, как персонажи видят друг друга?

### При раскадровке

- Фиксируй направление взгляда персонажей → определяй ось → соблюдай правило 180°
- Определяй направление движения в кадре → обеспечивай непрерывность
- Обозначай, когда хочешь нарушить правило намеренно (и почему)

### Работа с клиентом

Когда клиент говорит «что-то не то с кадрами» — часто это нарушение правила 180° или направления движения. Объясни: «Персонажи смотрят в разные стороны — зритель теряет ориентацию». Клиент поймёт.

---

## Быстрая проверка перед финалом

- [ ] Ось 180° зафиксирована и соблюдается (или нарушена намеренно)?
- [ ] Направление движения персонажей последовательно?
- [ ] Смена ракурсов ≥ 30° (или есть оправдание)?
- [ ] Есть ли у каждого персонажа цель, препятствие и действие в сцене?
- [ ] Как персонажи видят друг друга — и меняется ли это в ходе сцены?
