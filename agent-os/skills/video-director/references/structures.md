# Структуры под форматы

## 15 секунд — Реклама / Performance

```
0–2с   Hook        → визуальный удар, вопрос или контраст
2–8с   Проблема    → узнаваемая ситуация "до"
8–12с  Решение     → продукт / действие / поворот
12–15с Payoff+CTA  → результат + один призыв
```

Правило: каждые 2–3 секунды — смена кадра или информации.
Диалог — только если без него нельзя. Предпочтение — text overlay + визуал.

---

## 30 секунд — Органика / Бренд

```
0–3с   Hook         → in medias res или визуальный шок
3–10с  Контекст     → кто, где, какая ситуация
10–18с Конфликт     → нарастание, pattern interrupt на ~14с
18–25с Поворот      → неожиданное решение / момент
25–30с Payoff + CTA → эмоция + действие
```

Pattern interrupt на ~14с обязателен — к этому моменту часть зрителей начинает уходить.

---

## 45–60 секунд — Мини-фильм / Сторителлинг

```
0–3с   Hook         → сильный визуальный или смысловой удар
3–12с  Setup        → герой + цель + мир
12–25с Конфликт     → препятствие, эскалация, PI на ~20с
25–40с Кульминация  → пик напряжения / поворот
40–55с Payoff       → разрешение + трансформация героя
55–60с CTA / финал  → логотип / фраза / призыв
```

Twist в конце (финал переосмысляет начало) — самый вирусный формат для этой длины.

---

## 2–3 минуты — YouTube (короткий)

```
0–10с  Hook         → большое обещание или интригующий кадр
10–30с Setup        → контекст, герой, ставки
30–60с Акт 1        → первые препятствия, углубление
60–90с Акт 2        → кульминация, поворот, PI каждые 20–30с
90–150с Акт 3       → разрешение, трансформация
150–180с Payoff+CTA → вывод + призыв
```

Pattern interrupt каждые 20–30с. Одна главная мысль / инсайт на весь ролик.

## Структуры по типу контента

### Продуктовая реклама (Hook → Evidence → Payoff)
```
Hook:      обещание результата
Evidence:  быстрая цепочка — шаги, before/after, факты
Payoff:    финальный результат + интеграция смысла хука
```

### Образовательный ролик (AIDA-compact)
```
Attention:  2с — визуальный/текстовый хук
Interest:   5с — демонстрация проблемы
Desire:     15с — один сильный инсайт или решение
Action:     3–5с — CTA
```

### Брендовое кино (Emotional Arc)
```
Нейтральное → Напряжение → Микрорельефы → Кульминация → Катарсис
```
Продукт появляется только в финале как символ решения, а не в середине.

### Вирусная органика (Twist-drama)
```
Стандартная ситуация → нарастание → TWIST в конце, который переворачивает смысл начала
```
Финал должен заставить пересмотреть первые кадры.

## Эмоциональные дуги (примеры)

**Реклама**: Боль → Узнавание → Облегчение → Желание
**Органика**: Любопытство → Напряжение → Удивление → Удовлетворение
**Бренд-кино**: Спокойствие → Тревога → Напряжение → Катарсис → Тепло
**Образовательное**: Скептицизм → Интерес → "Ого" → Желание применить
