# Руководство пользователя — скилл «Стилист»

Это пошаговая инструкция, как пользоваться скиллом и получить готовый персональный сайт-гардероб. Подходит и тем, кто впервые работает с ИИ.

---

## Что делает скилл

Скилл проводит полный стилистический разбор человека и собирает из него **персональный сайт** из 4 страниц:

- **Профиль** — цветотип, тип фигуры, палитра с точными HEX, силуэты, ткани, волосы, макияж/уход, украшения, золотые правила.
- **Гардероб** — каталог конкретных вещей со ссылками на магазины, с группировкой по категориям / магазинам / цветам / вердиктам.
- **Луки** — готовые образы по поводам + таблица «что носится чаще всего».
- **Сочетания** — матрица «каждый верх × каждый низ» с советами по стилизации.

Работает для любого человека — любого пола, возраста и стиля жизни.

---

## С чего начать (3 способа запустить)

Просто напишите Claude естественным языком, например:

- «Разбери мой цветотип и собери капсулу» (приложите фото)
- «Сделай стилистический разбор для подруги»
- «Помоги клиенту со стилем, собери сайт-гардероб»
- «Что мне идёт? Подбери палитру и фасоны»

Скилл подхватится автоматически и поведёт вас по этапам.

---

## Что подготовить заранее (необязательно, но ускорит)

1. **Фото для цвета** — лицо крупным планом при дневном свете у окна, **без макияжа и фильтров**, волосы убраны от лица. 2–3 кадра. Хорошо, если есть кадр с золотым и с серебряным украшением у лица.
2. **Фото фигуры** — в облегающей одежде, анфас и профиль.
3. **Замеры** (см) — рост, вес, грудь, талия, бёдра, запястье и т.д. Что есть — то и дайте.
4. **Контекст** — город/климат, чем занимаетесь, бюджет, что уже любите носить, что не носите.

> **Нет фото?** Не страшно. Скилл перейдёт в режим опросника (вопросы про вены на запястье, реакцию на золото/серебро, цвет глаз и волос и т.д.). Результат будет чуть менее точным — скилл вас об этом честно предупредит.

---

## Как проходит работа (7 этапов)

Скилл ведёт вас по шагам и **спрашивает подтверждение** на ключевых развилках — не пропускайте их, именно так разбор получается точным.

1. **Сбор данных** — скилл задаёт вопросы порциями.
2. **Цвет** — определяет цветотип по 12-сезонной системе (+ сверка по корейской школе) и собирает палитру.
3. **Фигура** — тип линий (система Кибби), силуэты «работает / не работает», длины, ткани.
4. **Профиль** — всё это складывается в единый профиль.
5. **Капсула** — сначала текстовый список вещей (вы его утверждаете), потом реальные товары со ссылками.
6. **Луки и сочетания** — готовые образы и матрица сочетаний.
7. **Сайт** — генерируется автоматически, вам отдают ссылки на готовые файлы.

На каждом этапе можно возразить: «этот цвет меня гасит», «не ношу мини» — скилл пересчитает. **Ваша обратная связь важнее теории.**

## Технические детали (для тех, кто запускает генератор сам)

Все данные разбора хранятся в одном файле `wardrobe.json`. Сайт собирается из него скриптом.

### Окружение

- Нужен **Python 3**: `python3 --version`.
- Для конвертации фото товаров — библиотека Pillow (только если будете добавлять фото):
  ```bash
  pip install pillow --break-system-packages
  pip install pillow-avif-plugin --break-system-packages   # для AVIF-фото из магазинов
  ```
- Сам генератор сайта зависимостей не требует.

### Проверить данные перед сборкой

```bash
python3 assets/build_site.py wardrobe.json ./сайт --check
```
Покажет ошибки (дубликаты id, ссылки на несуществующие вещи) и предупреждения. Ничего не записывает. Исправьте ошибки в `wardrobe.json` и повторите.

### Собрать сайт

```bash
python3 assets/build_site.py wardrobe.json ./сайт
```
Создаст в папке `./сайт` файлы `Profile.html`, `Lookbook.html`, `Looks.html`, `Combinations.html`. Страницы Луки/Сочетания появляются только если в данных есть соответствующие разделы — навигация подстраивается сама. Если есть фото — положите рядом папку `images/`.

### Добавить фото товаров

1. Скачайте фото вещей в папку `images/`, называя файлы по id вещи (`7.jpg`, `12.avif`).
2. Приведите к PNG:
   ```bash
   python3 assets/convert_images.py ./images
   ```
3. В `wardrobe.json` у каждой вещи пропишите путь: `"img": "images/7.png"`.

Нет фото — оставьте `"img": ""`, сайт покажет аккуратную цветную заглушку.

## Структура wardrobe.json (коротко)

Полный заполненный образец — `assets/wardrobe.example.json`. Он **вымышленный** и нужен только чтобы показать структуру; не переносите его данные на реального человека.

- `config` — заголовок и подзаголовки сайта.
- `person` — весь профиль: `archetype`, `identity`, `measurements`, `palette` (`base`/`accent`/`anchor`/`no`), `silhouettes`, `fabrics`, `hair`, `makeup`, `jewelry`, `context`, `goldenRules`. Неприменимые блоки можно опустить.
- `items` — массив вещей: `id`, `category`, `name`, `brand`, `colorName`, `colorHex`, `url`, `verdict` (`yes`/`maybe`/`no`), `note`, `img`.
- `looks` — образы: `id`, `name`, `occasion`, `icon`, `items` (массив id), `why`, `trick`.
- `combinations` — `tops`, `bottoms` (массивы id) и `matrix` с ключами `"<topId>_<bottomId>"` → `{mood, tip}`.

## Частые вопросы

**Сайт не собрался / ошибка JSON.** Запустите с `--check` — он точно скажет, где проблема. Чаще всего это лишняя запятая или ссылка на id вещи, которой нет в `items`.

**Фото AVIF не конвертируется.** Установите плагин: `pip install pillow-avif-plugin --break-system-packages`.

**Можно ли отредактировать готовый HTML руками?** Не рекомендуется. Меняйте `wardrobe.json` и пересобирайте — так результат остаётся стабильным.

**Подходит ли скилл для мужчин?** Да. Скилл адаптирует категории и заменяет макияж на уход/грумминг — структура не меняется.
