# admin — Профессиональная админ-панель (React)

Управление турбазой: дашборд, брони, домики, клиенты, настройки.
Работает поверх backend API (server/) под авторизацией.

## Структура
- `src/pages/`       — разделы панели (Dashboard, Bookings, Cottages, Clients, Settings)
- `src/components/`  — таблицы, формы, модалки, графики
- `src/layouts/`     — каркас панели (сайдбар, топбар, контент)
- `src/api/`         — клиент к backend, авторизация
- `src/hooks/`       — переиспользуемые React-хуки (данные, авторизация)
- `src/styles/`      — стили панели
