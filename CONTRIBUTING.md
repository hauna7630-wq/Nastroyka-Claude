# Участие в разработке

Полное руководство для контрибьюторов находится в документации:

➡️ **[docs/contributing/CONTRIBUTING.md](./docs/contributing/CONTRIBUTING.md)**

Кратко:

1. Настройте окружение: [docs/getting-started/installation.md](./docs/getting-started/installation.md)
2. Создайте рабочую ветку от `main`: [docs/contributing/git-workflow.md](./docs/contributing/git-workflow.md)
3. Внесите изменения и покройте их тестами: [docs/guides/testing.md](./docs/guides/testing.md)
4. Прогоните `npm test` и откройте Pull Request в `main`.

Вся документация — в каталоге [`docs/`](./docs/README.md).
