# 🎨 Стиль кода

Единый стиль упрощает чтение и поддержку кода.

## Основное

- **Язык:** JavaScript (Node.js), модули — CommonJS (`require` / `module.exports`).
- **Отступы:** 2 пробела.
- **Точки с запятой:** да, ставим.
- **Кавычки:** одинарные `'...'`.
- **Именование:**
  - переменные и функции — `camelCase`;
  - классы — `PascalCase` (например, `TaskQueue`);
  - константы-конфиги — `camelCase` или `UPPER_SNAKE_CASE` для «настоящих» констант.

## Функции

- Одна функция — одна задача.
- Делайте функции чистыми, где это возможно (без скрытых сайд-эффектов).
- Явно возвращайте значение; избегайте неявных мутаций аргументов.

```js
// Хорошо: не мутирует исходный массив
function sortByField(arr, field) {
  return [...arr].sort((a, b) => (a[field] > b[field] ? 1 : -1));
}
```

## Асинхронный код

- Предпочитайте `async/await` вместо цепочек `.then()`.
- Всегда обрабатывайте ошибки промисов.
- Очищайте таймеры (`clearTimeout`) во избежание утечек — как в `fetchWithTimeout`.

## Экспорты

Экспортируйте публичный API одним объектом в конце файла:

```js
module.exports = { buildConfig, defaults };
```

## Комментарии

- Комментируйте **почему**, а не **что** (код и так показывает «что»).
- Не оставляйте закомментированный «мёртвый» код.

## Форматирование

Если в проект будут добавлены [Prettier](https://prettier.io/) и [ESLint](https://eslint.org/) — следуйте их правилам, а ручные настройки в этом файле станут вторичными.
