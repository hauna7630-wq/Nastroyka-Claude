# 🚀 Установка

## Требования

| Инструмент | Версия | Назначение |
|------------|--------|------------|
| [Node.js](https://nodejs.org/) | 18.x или 20.x | Среда выполнения |
| npm | 9+ (идёт с Node.js) | Менеджер пакетов |
| git | любая актуальная | Контроль версий |

> Проект тестируется в CI на Node.js **18.x** и **20.x** — используйте одну из этих версий, чтобы локальное поведение совпадало с CI.

Проверить установленные версии:

```bash
node --version   # ожидается v18.x.x или v20.x.x
npm --version
git --version
```

## Клонирование репозитория

```bash
git clone https://github.com/hauna7630-wq/Nastroyka-Claude.git
cd Nastroyka-Claude
```

## Установка зависимостей

Для воспроизводимой установки (как в CI) используйте `npm ci`:

```bash
npm ci
```

Если файла `package-lock.json` нет или вы добавляете новые пакеты — используйте:

```bash
npm install
```

> **`npm ci` vs `npm install`:** `npm ci` ставит зависимости строго по `package-lock.json` и не меняет его — это быстрее и надёжнее для CI и чистой установки. `npm install` может обновлять lock-файл.

## Проверка установки

Запустите тесты — если они проходят, окружение настроено корректно:

```bash
npm test
```

## Возможные проблемы

- **`command not found: node`** — Node.js не установлен или не добавлен в `PATH`. Установите его с [nodejs.org](https://nodejs.org/) или через [nvm](https://github.com/nvm-sh/nvm).
- **Несовместимая версия Node** — переключитесь на 18.x или 20.x: `nvm install 20 && nvm use 20`.
- **Ошибки при `npm ci`** — удалите `node_modules` и попробуйте снова: `rm -rf node_modules && npm ci`.
