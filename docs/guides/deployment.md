# 📦 Развёртывание и CI/CD

## Непрерывная интеграция (CI)

CI настроен через GitHub Actions: [`.github/workflows/test.yml`](../../.github/workflows/test.yml).

### Когда запускается

- при `push` в ветку `main`;
- при открытии/обновлении Pull Request в `main`.

### Что делает

1. Поднимает окружение на Node.js **18.x** и **20.x** (матрица версий).
2. Ставит зависимости через `npm ci`.
3. Прогоняет тесты с отчётом JUnit:
   ```bash
   npm test -- --ci --reporters=default --reporters=jest-junit
   ```
4. Сохраняет результаты тестов как артефакт (`reports/`).

### Локальное воспроизведение CI

```bash
npm ci
npm test -- --ci
```

## Релизы

Этапы выпуска новой версии:

1. Убедитесь, что все тесты проходят (CI зелёный).
2. Обновите версию в `package.json` по [SemVer](https://semver.org/lang/ru/):
   - **PATCH** (`1.0.x`) — исправления, обратно совместимые;
   - **MINOR** (`1.x.0`) — новая функциональность без слома совместимости;
   - **MAJOR** (`x.0.0`) — несовместимые изменения.
3. Зафиксируйте изменения в [CHANGELOG.md](../../CHANGELOG.md).
4. Поставьте git-тег:
   ```bash
   git tag -a v1.0.1 -m "Release v1.0.1"
   git push origin v1.0.1
   ```

## Чек-лист перед развёртыванием

- [ ] CI зелёный на всех версиях Node.js
- [ ] Версия в `package.json` обновлена
- [ ] `CHANGELOG.md` дополнен
- [ ] Секреты не попали в репозиторий
- [ ] Документация актуальна
