# Архитектура

Монорепозиторий с тремя приложениями:

- **server/** — Express REST API (CommonJS). Источник правды: брони, домики, клиенты.
- **web/**    — публичный сайт турбазы (React/Next.js) для гостей.
- **admin/**  — админ-панель (React) для управления, поверх API под авторизацией.

```
[ web ]  ──┐
           ├──>  [ server API ]  ──>  [ данные/БД ]
[ admin ] ─┘
```

Корневые `src/` + `tests/` — учебные утилиты и демонстрация флаки-тестов
(см. CLAUDE.md), не часть продакшен-сайта.
