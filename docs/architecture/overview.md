# 🏛 Обзор архитектуры

## Общая картина

Проект — это набор небольших независимых модулей на Node.js (CommonJS), каждый из которых отвечает за одну зону ответственности. Внешних зависимостей в рантайме нет; в разработке используется только Jest для тестов.

```
┌─────────────────────────────────────────────┐
│                  Потребитель                  │
│            (приложение / тесты)               │
└───────────────┬───────────────────────────────┘
                │ require()
        ┌───────┴────────┬────────────┬──────────┐
        ▼                ▼            ▼          ▼
   ┌─────────┐     ┌──────────┐  ┌────────┐  ┌────────┐
   │ config  │     │   api    │  │ queue  │  │ utils  │
   │         │     │ (+ cache)│  │        │  │        │
   └─────────┘     └──────────┘  └────────┘  └────────┘
```

## Модули и зоны ответственности

| Модуль | Ответственность | Состояние |
|--------|-----------------|-----------|
| `config.js` | Сборка конфигурации из значений по умолчанию и переопределений | Без состояния |
| `api.js` | Доступ к «пользователям», пагинация | Кэш в `Map` на уровне модуля |
| `queue.js` | Очередь задач, счётчики, асинхронные хелперы | Глобальный счётчик на уровне модуля |
| `utils.js` | Утилиты общего назначения (даты, сортировка, debounce) | Без состояния |

## Ключевые принципы

1. **Маленькие модули.** Каждый файл — одна зона ответственности, экспортирует минимально необходимый набор функций.
2. **Явные зависимости.** Модули не тянут друг друга без необходимости; конфигурация передаётся аргументами.
3. **Тестируемость.** Для модулей с состоянием есть функции сброса (`clearCache`, `resetCounter`).
4. **Нет скрытых сайд-эффектов** при импорте, кроме инициализации пустого кэша/счётчика.

## Состояние на уровне модулей: важно знать

Два модуля хранят состояние в области видимости модуля:

- `api.js` — `cache` (`Map`). Сбрасывается через `clearCache()`.
- `queue.js` — `globalCounter`. Сбрасывается через `resetCounter()`.

> Поскольку Node.js кэширует модули, это состояние **разделяется** между всеми, кто импортирует модуль. В тестах сбрасывайте его в `beforeEach`, чтобы тесты не влияли друг на друга.
