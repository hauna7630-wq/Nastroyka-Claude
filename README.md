# Nastroyka-Claude

Небольшой проект на Node.js. Полная документация — в каталоге [`docs/`](./docs/README.md).

## Быстрый старт

```bash
npm ci      # установка зависимостей
npm test    # запуск тестов
```

Требуется Node.js **18.x** или **20.x**.

## Структура проекта

```
src/                  Исходный код (api, config, queue, utils)
tests/                Тесты на Jest
docs/                 Документация и инструкции
.github/workflows/    CI (GitHub Actions)
```
