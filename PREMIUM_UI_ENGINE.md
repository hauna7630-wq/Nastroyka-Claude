## 3. ПРОТОКОЛ АВТОНОМНОГО ЦИКЛА (`/loop` & Self-Correction)

При активации автономного режима (`/loop` или авто-режим в CLI) Claude обязан
следовать жесткому алгоритму:

1. **Этап инициализации и брифинга:**
   Перед генерацией первой строчки кода модель останавливает выполнение и
   запрашивает у пользователя:
   * Бизнес-вертикаль продукта и целевую аудиторию.
   * Желаемый визуальный вектор (например: *Dark Cyberpunk / Скандинавский
     минимализм / Строгий швейцарский корпоративный стиль*).
   * Технологический стек и архитектурные ограничения.

2. **Этап изолированной сборки:**
   Запрещено перегружать проект внешними тяжелыми библиотеками без явной
   необходимости. Если интерактивный эффект реализуется нативным CSS/JS —
   использовать нативные решения для сохранения высокого FPS.

3. **Этап автономной верификации (Self-Correction Loop):**
   Если сгенерированный компонент (анимация, форма, интерактивный график)
   выдает ошибку или некорректно рендерится, Claude обязан:
   * Самостоятельно запустить локальный сервер сборщика.
   * Снять логи ошибок из терминала / виртуальной консоли браузера.
   * **Провести до 3-5 циклов автоматического исправления ошибок**, не прерывая
     сессию и не запрашивая одобрения пользователя, пока код не станет валидным,
     а интерфейс — рабочим.

## 4. ГЛОБАЛЬНЫЙ ЧЕК-ЛИСТ КАЧЕСТВА ИНТЕРФЕЙСА

Любой создаваемый код фронтенда проверяется на соответствие четырем столпам
дорогого продукта:

### 📐 Сетка и Пространство (Layout & Negative Space)
* Использование "свободного воздуха": не менее 30-40% экрана должно оставаться
  свободным от контента для создания ощущения премиальности.
* Кастомный брейкпоинт-менеджмент для ультрашироких мониторов (4K) и
  нестандартных экранов.

### ✨ Управление вниманием (Micro-interactions & Polish)
* **Cursor-Aware Эффекты:** Интерактивные элементы должны реагировать на вектор
  движения мыши (мягкое радиальное свечение, смещение теней, легкий параллакс).
* **Smooth Reveal:** Контент не должен «моргать» при загрузке. Обязательны
  микро-эффекты появления (fade-in-up) с использованием кривых Безье.

### 📱 Премиальный Mobile-First
* Мобильная версия не является простым «сжатием» десктопа.
* Полная перестройка UX: замена громоздких таблиц на кастомные свайп-карточки,
  оптимизация зон досягаемости большого пальца, использование нативных мобильных
  паттернов (bottom sheets, drawer-меню).

### ⚙️ Инженерный перформанс (Invisible Details)
* Оптимальная семантика (теги `main`, `section`, `nav`, `aside`).
* Использование современных форматов медиа (`.webp`, `.svg`, `.webm`).
* Наличие состояний загрузки (skeletons) и кастомных обработчиков пустых
  состояний (empty states).

## SELF-CORRECTION LOOP

При обнаружении ошибок, конфликтов, деградации качества или несоответствия
требованиям запрещено останавливаться после первой попытки исправления.

Необходимо:

1. Провести анализ причины
2. Выполнить исправление
3. Выполнить повторную проверку
4. Повторить цикл до 3 раз

Если проблема сохраняется:

- остановить цикл
- предоставить отчет
- описать причину
- предложить варианты решения

Запрещено бесконечное зацикливание.
